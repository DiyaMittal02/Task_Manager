# 🚀 React Task Manager - Modern UI

A visually stunning and responsive Task Manager application built with React.js and styled with Tailwind CSS. This project features a dynamic, animated gradient background and a sleek, "glassmorphism" UI for a modern user experience.



## ✨ Features

-   **Dynamic UI**: An animated gradient background and semi-transparent "glass" cards create a beautiful, modern aesthetic.
-   **Full CRUD Functionality**: Add, view, complete, edit, and delete tasks.
-   **Task Filtering**: Easily filter tasks by their status: All, Completed, or Incomplete.
-   **Data Persistence**: Your tasks are automatically saved to `localStorage`, so they'll be there when you return.
-   **Responsive Design**: The UI is fully responsive and looks great on desktops, tablets, and mobile devices.
-   **Built with Modern Tools**: 100% React Hooks, no class components.

## 🛠️ Built With

-   [React.js](https://reactjs.org/) (Functional Components & Hooks)
-   [Tailwind CSS](https://tailwindcss.com/) (for styling and the modern UI)
-   [Google Fonts](https://fonts.google.com/) (using the "Inter" font for clean typography)

## 🔧 Local Setup & Installation

To run this project on your local machine, follow these steps:

### 1. Clone the Repository
Clone this project to your local machine.
```sh
git clone [https://github.com/your-username/react-task-manager.git](https://github.com/your-username/react-task-manager.git)
cd react-task-manager
```

### 2. Install Dependencies
Install all the required npm packages.
```sh
npm install
```

### 3. Run the Development Server
Start the application.
```sh
npm start
```
The application will open automatically in your browser at `http://localhost:3000`.

## 📝 Notes

-   **State Management**: All application state is managed within the `App` component using `useState` and `useEffect` hooks.
-   **Data Storage**: The app uses the browser's `localStorage` to persist task data, making it a fast, client-side-only application.
